# govulncheck-sarif-result-location

Sets physical location for findings of SARIF report generated by [govulncheck](https://pkg.go.dev/golang.org/x/vuln/cmd/govulncheck) parsing given report file and [go.mod](https://go.dev/doc/modules/gomod-ref) file for which the report was generated.

If SARIF report finding is about module which can be found in given go.mod, then locations\[0\].physicalLocation.region.startLine is given line number which references Go module which finding is caused by.

If SARIF report finding is about Go [standard library](https://pkg.go.dev/std), then locations\[0\].physicalLocation.region.startLine is given line number which references Go version, i.e. [go](https://go.dev/doc/modules/gomod-ref#go) directive.

## Building

```shell
make build
```

## Using

```shell
./.build/govulncheck-sarif-result-location -report sarif-report.json -gomod "$(go env GOMOD)" -out sarif-report.json 
```
